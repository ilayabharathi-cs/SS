# SmartShield IoT Security — Snort IDS Integration

This directory contains the defensive Snort 3 Intrusion Detection System (IDS) configuration, custom rules, and documentation for the **SmartShield IoT Security System**.

## System Requirements & Installation

- **OS**: Kali GNU/Linux Rolling (or Debian/Ubuntu)
- **Package**: `snort` (version 3.x)

To install Snort 3 on Kali Linux:
```bash
sudo apt-get update
sudo apt-get install -y snort
```

Verify installation:
```bash
snort -V
```

---

## Directory Structure

```
security/
└── snort/
    ├── snort.conf           # Snort 3 main configuration file
    ├── rules/
    │   └── smartshield.rules # Custom defensive lab detection rules
    └── README.md            # Setup guide
```

---

## SmartShield Rules

1. **Rule 1000001**: Detects ICMP ping echo requests (`sid:1000001`).
2. **Rule 1000002**: Detects TCP network traffic targeting SmartShield API port 8000 (`sid:1000002`).
3. **Rule 1000003**: Detects standard HTTP traffic on port 80 (`sid:1000003`).

---

## Running Snort in Alert Mode

Run Snort 3 on the active network interface (`wlan0`):

```bash
snort -c security/snort/snort.conf -i wlan0 -A alert_json
```

Alert logs generated by Snort are consumed by the SmartShield backend parser and stored in PostgreSQL (`security_alerts` table).
